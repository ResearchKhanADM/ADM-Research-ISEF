## What would reverse this

The observation, result, or failure that would send this back. Name a number and
a direction wherever possible: *"if the Q-value ranking flips when the sampling
box is halved"* is reversible; *"if it turns out to be wrong"* is not.

This section is the point of the file. A decision whose reversal condition
cannot be stated was probably a preference, not a decision.
